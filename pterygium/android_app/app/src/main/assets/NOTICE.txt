Eye Map Lab: experimental Android adaptation of Microsoft SmartKC. SmartKC code copyright Microsoft Corporation, MIT license. Model/data attribution retained under the included SmartKC data license (CC BY 4.0). Original project: https://github.com/microsoft/SmartKC-A-Smartphone-based-Corneal-Topographer . Changes: native Java localisation, Arc-Step, independent standard real Zernike basis, on-device rendering, isolated test UI. The original Python Zernike library is not bundled. No clinical accuracy is established.
